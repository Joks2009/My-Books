MY BOOKS - V1 WEB APP

What is included
- Mobile-first iPhone-friendly PWA
- Add a book with photo/camera
- Local storage on the device
- Title, author, status, genre, mood, rating, favorite, date, summary and personal opinion
- Read / Want to read / Favorites filters
- Search and Explore filters
- Simple reading statistics
- Edit and delete
- Optional browser OCR for title/author using Tesseract.js when online
- Add to Home Screen support once hosted over HTTPS

How to try locally
1. Open index.html in a browser.
2. Data is stored in that browser's local storage.

How to put it on an iPhone
The folder needs to be hosted on an HTTPS website. Free static hosting such as GitHub Pages, Netlify, Cloudflare Pages or Vercel can host it. Once opened in Safari on the iPhone, use Share -> Add to Home Screen.

Important limitation of V1
Data is local to that browser/device. Clearing website data can remove it. Cloud backup/sync can be added later.
